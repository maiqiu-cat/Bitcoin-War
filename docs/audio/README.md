# 战场音频（背景音乐 + 战斗音效）

全部用 Web Audio **实时合成**，不使用任何音频文件：没有版权问题，也不增加下载量。打包后的 JS 增加约 18KB（gzip 后约 6KB）。代码在 `src/audio/`：

| 文件 | 职责 |
| --- | --- |
| `mix.ts` | 纯逻辑，有单测：空间化（`spatial`）、并发限流（`VoiceLimiter`）、行情转强度（`musicIntensity`、`smoothIntensity`）、各声部音量（`layerGains`）、和弦进行、鼓点和贝斯编排 |
| `instruments.ts` | 合成乐器和音效。每个函数都显式传入 `BaseAudioContext`，所以同一套代码能同时用于实时 `AudioContext` 和离线 `OfflineAudioContext` |
| `music.ts` | `MusicDirector`：16 分音符步进，前瞻 0.25 秒排程；6 个声部各有一个 GainNode，随强度平滑淡入淡出 |
| `engine.ts` | `AudioEngine`：混音总线、混响、压限、解锁和开关、页面隐藏时暂停、音效 API；`renderPreview()` 用于离线渲染试听 WAV |

## 信号链

```
各音效 ─ StereoPanner ─┬─ sfx 总线 (0.9) ──┐
                      └─ 混响发送 ──┐      │
配乐各声部 ─ 声部增益 ─┬─ music 总线 (0.42) ┤
                      └─ 混响发送 ──┤      │
                       混响(2.4s 程序化 IR) ×0.32
                                    └──────┴─ master (0.85) → 28Hz 高通 → 压限器(-16dB, 4:1) → 输出
```

## 配乐：D 小调，92 BPM，随行情加码

- 和弦进行：Dm → B♭ → Gm → A，每小节换一个和弦，约 2.6 秒一小节。
- **强度**：0 到 1，由 `musicIntensity()` 根据最近 5 秒的主动买卖流量、战线离中心的距离、最近 1 分钟的大单和爆仓数量计算；双方猛攻基地时至少 0.85。强度上升时约 3 秒跟上，下降时约 9 秒才回落。

| 声部 | 何时进入（强度） |
| --- | --- |
| 弦乐铺底（失谐锯齿波 + 低通） | 一直在，0.55 → 1 |
| 低音长音 D2 | 一直在 |
| 太鼓（第 1、3 拍；强度高时加切分） | 0.2 → 0.45 |
| 贝斯（八分音符根音 + 八度） | 0.25 → 0.5 |
| 军鼓 + 装饰音 + 镲（强度高时变成 16 分音符） | 0.45 → 0.7 |
| 铜管和弦短奏 | 0.7 → 0.9 |

胜利号曲响起时，配乐自动压低约 2.6 秒。

## 音效：画面上的每个事件都有对应的声音

| 事件（`world.ts`） | 声音 | 限流（每秒最多） |
| --- | --- | --- |
| 前线对射 | 步枪：带通噪声 + 低频冲击，频率随机 | 9 |
| 大单开炮 | 坦克炮：低频重击 + 收拢的低通噪声 | 4 |
| 炮弹着地、攻陷后的连环爆炸 | 爆炸：超低频 boom、噪声主体、碎裂声，时长随规模变长 | 6 |
| 爆仓重炮 | 先有一段**呼啸**（高音滑落，时长等于炮弹飞行时间），落地后是加大 25% 的爆炸 | 3 |
| 期权大单 | 信号弹：上扫的噪声 + 「啪」 | 2 |
| 新回合开始 | 号角：D4 → A4 铜管 | — |
| 回合胜利 | 号曲：牛方大调，熊方小调，加太鼓 | — |
| 打开声音 | 轻点击 | — |

**空间化**：把事件位置投影到屏幕上，得到 x（−1 到 1）作为左右声道，乘以 0.85 避免完全偏到一边。音量 = `(ref/(ref+距离))^1.1`，最低 0.05；位于镜头背后的事件直接放到一侧。

## 浏览器规则和开关

- 浏览器不允许网页在用户操作之前出声。用户第一次 **点击、按键或触摸** 时调用 `audio.unlock()`；在此之前，HUD 底部会显示「点击画面任意位置，开启战场音效」。
- 右上角的喇叭按钮或 **M 键** 可以开关声音，选择记在 `localStorage['bb.sound']`。URL 加 `?sound=0` 可以临时关闭。
- 页面隐藏（切到其他标签页）时，音频上下文会 `suspend`，回来后再 `resume`。

## 调音的地方

| 想调什么 | 改哪里 |
| --- | --- |
| 总音量、音乐和音效的比例、混响量 | `engine.ts → buildGraph`（master 0.85、music 0.42、sfx 0.9、reverb 0.32） |
| 某种音效的密度 | `engine.ts` 里 `VoiceLimiter` 的配置 |
| 音色 | `instruments.ts` 里对应的函数 |
| 编曲和声部进入的门槛 | `mix.ts → layerGains / drumPattern / bassLine / PROGRESSION` |
| 配乐对行情的敏感度 | `mix.ts → musicIntensity`，以及 `smoothIntensity` 的 attack 和 release |

## 验证

```bash
pnpm test                       # tests/audio.test.ts（10 个）
pnpm build && pnpm verify:audio # 无头 Chrome：锁定 → 点击解锁 → 音效链路 → M 键开关 → 离线渲染 32s 试听
open verification/audio-preview.wav
```

`verify:audio` 检查以下几项，报告写在 `verification/audio-report.json`：

- 解锁前后的状态切换和提示条显示
- 音效链路没有运行时错误
- M 键开关和偏好记忆
- 试听文件的峰值低于 0.995（不爆音）
- 平均响度在 −32 到 −8 dBFS 之间
- 激战段比平静段至少响 3dB

2026-10-01 的结果：峰值 0.875，平均 −16.1 dBFS，平静段 −23.1 dB，激战段 −14.4 dB，全部通过。

**局限**：程序化合成的质感比不上专业录音素材。以后可以按同样的接口（`instruments.ts` 里的函数签名）换成采样播放；要用素材，记得核对授权，并压缩后放进 `public/`。
