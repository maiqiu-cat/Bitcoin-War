# HUD 与多语言

## HUD 布局（`src/ui/hud.ts` + `styles.css`）

```
└──────────────────────┘        │ ┌ 战况条 .warbar ─────────────┐ │
                                │ │← 熊方胜利线  播报  牛方胜利线→│ │

│ 订单簿深度 [数据源▼]             │                                 │ 市场动态 ● 实时                     │
│ canvas 累计深度（渐变、买卖墙）   │                                 │ 时间 交易所 类型 金额（最多 8 条）    │
│ 价格轴 · 兵力图例                │                                 └───────────────────────────────────┘

```

- **元素引用**：模板里写 `data-k="xxx"`，构造时收集到 `this.el.xxx`。
- **静态文案**：写 `data-i18n="key"`，悬停提示写 `data-i18n-title="key"`。切换语言时 `applyLang()` 会统一重写这些元素，同时重新渲染动态内容：播报、比分、图例、涨跌、数据源下拉框、市场流水，以及正在显示的横幅。
- **更新频率**：
  - 每个 tick（250ms）：`setPrice`、`setRound`、`drawDepth`
  - 每秒：`setLiquidity`、`setVenues`、`setSources`、`setRegime`
  - 每帧：`frame(dt)` 做补间
  - 事件到达时：`addFeed`
- **对外回调**（`HudCallbacks`）：`onLighting`、`onCinematic`、`onSource`、`onFocus`，在 `main.ts` 里接线。

## 小屏布局（2026-10-02，`styles.css` 末尾三段媒体查询）

| 条件 | 适用 | 规则 |
| --- | --- | --- |
| 宽 ≤1100px 或 高 ≤500px | 手机（竖横）、平板、窄窗口 | 隐藏左上面板、两侧流动性、交易所列表、操作提示。菜单只留图标（文字留在悬停提示里），和标题同排；价格与 24 小时涨跌并排在第二行（`.top-center` 改成网格）；战况条、底部两个面板、横幅、3D 标签整体缩小字号；声音提示条移到画面中部（56%），不再压住底部面板 |
| 宽 ≤600px，或高 ≤500px | 手机 | 用简称：市场动态的「大额买入」显示为「买入」（`feedShort.*`），英文深度标题显示为 DEPTH（`depthTitleShort`）。模板里同时放 `<em class="full">` 和 `<em class="short">`，由 CSS 切换 |
| 宽 ≤600px | 手机竖屏 | 标题靠左并给右侧菜单留出约 186px；价格 26px；深度图高 72px；市场动态最多 6 条 |
| 高 ≤500px | 手机横屏 | 隐藏标题，价格行与菜单同高；上中区宽度 `min(460px, 100vw − 380px)`；底部两个面板缩到 30vw 放在两角，深度图高 44px，动态最多 4 条；声音提示放在两个面板之间；横幅放在 46% 高度 |
| 宽 1101–1271px | 笔记本窄窗口 | 上中区宽度 `min(580px, 100vw − 692px)`，避开右上 318px 的面板 |

- **深度图文字**：画布宽度 <300px 时字号 8.5px；买墙和卖墙放不进一行时，卖墙换到第二行，图表顶部相应下移；单条仍放不下就去掉「@ 价格」。
- **3D 标签**（`world.fitReserveLabels`）：储备标签会被屏幕边缘切掉、或落在任一 HUD 面板下面时淡出（`.cut`）。面板位置由 `hud.obstacles()` 提供，最多每 250ms 取一次。爆炸金额飘字落在屏幕左右边缘时不显示。
- **iOS**：`text-size-adjust: 100%`，防止横屏时 Safari 自动放大字号。
- **检查**：`pnpm build && pnpm verify:mobile`（[验证手册](../verification/README.md)）。改 HUD 或样式后必须全部通过，并亲自看手机竖屏、横屏截图。

## 多语言（`src/ui/i18n.ts`）

- **语言来源**：URL `?lang=zh|en` → `localStorage['bb.lang']` → `navigator.language`（以 zh 开头就用中文）。
- **切换方式**：右上角按钮（中文界面显示 EN，英文界面显示 中文）、L 键、`setLang()`。切换时会写入 localStorage，并广播 `onLangChange`。
- `t(key, vars)` 会把 `{name}` 换成变量值。找不到键时先回退到英文，再回退到键本身。
- 页面标题（`app.title`）和 `<html lang>` 会跟着语言变。

### 加一条文案

1. 在 `en` 和 `zh` 两个字典里各加同名的键，占位符 `{x}` 要一致。`banner.*Sub` 允许带 HTML（`<span class="b">`），其他文案按纯文本处理。
2. 静态元素写 `data-i18n="key"`；动态文案用 `t()`，并确认 `applyLang()` 切换语言时会重新渲染它。
3. 运行 `pnpm test`：`tests/i18n.test.ts` 会检查两份字典的键集合、占位符一致，以及所有 `StatusKey` 和 `FeedType` 都有翻译。

### 加第三种语言

1. 把 `Lang` 类型扩展成例如 `'zh' | 'en' | 'ja'`，加一个 `ja` 字典，注册到 `DICTS`。
2. `detect()` 里补上对应的 `navigator.language` 判断。
3. 把切换按钮从二选一改成下拉框（`hud.ts` 里的 `this.el.lang` 和 `lang.button`、`lang.title` 这两个键）。
4. 把测试里的语言列表补全。

### 约定

- 逻辑层不产出文案：`narrate()` 返回 `StatusKey`，`FeedItem.type` 是键。`FeedItem.label` 是英文，只供脚本和日志使用。
- 交易所名称不翻译，只有 `sim` 显示为「模拟器 / Simulator」。
